## Full-stack and web engineering

### Bidias E-Commerce Platform
A MERN-stack storefront with a product catalog, user accounts, Stripe payment processing, and an admin area. Built as the capstone for the NPower App Development Program.

Stack: React, TypeScript, Redux, Node.js, Express, MongoDB, Redis, Stripe, Docker

[Live demo](https://bidias-e-com-full-stack-app.netlify.app) · [Repository](https://github.com/eaglepython/Bidias-E-Com-FullStack-App)

### Nexus Weather Intelligence
A React weather app with geolocation, dynamic theming, five-day forecasts, and air quality data from the OpenWeatherMap API.

Stack: React, Vite, Tailwind CSS, OpenWeatherMap API

[Live app](https://eaglepython.github.io/Nexus/) · [Repository](https://github.com/eaglepython/Nexus)

### BookVault Library System
A vanilla-JavaScript digital library with an infinite carousel, external book APIs, search, and reading lists. No framework, just the platform.

Stack: JavaScript ES6+, HTML5, CSS3, Google Books API, Open Library API

[Live app](https://eaglepython.github.io/DOM-Project/) · [Repository](https://github.com/eaglepython/DOM-Project)

### Interactive JavaScript Portfolio
A pure-JavaScript portfolio built on the DOM and Canvas APIs, with matrix-rain and glitch effects and full keyboard navigation.

Stack: JavaScript, HTML5, CSS3, Canvas

[Live app](https://javascript-dom-portfolio.netlify.app/) · [Repository](https://github.com/eaglepython/JavaScript-DOM-Portfolio)

## AI governance and oversight

Browser prototypes that explore practical problems in AI oversight. Each runs on sample or simulated data and is labeled that way on purpose. None is deployed in an agency or company.

### Healthcare LLM Governance Toolkit
A front-end prototype for risk assessment and oversight of healthcare AI, with a weighted risk questionnaire and a mock oversight dashboard.

Stack: Python, FastAPI, React, TypeScript

[Live demo](https://eaglepython.github.io/healthcare-llm-governance-toolkit/) · [Repository](https://github.com/eaglepython/healthcare-llm-governance-toolkit)

### Multi-LLM Orchestration Platform
A prototype for routing requests across model providers with failover and cost awareness. The dashboard runs on sample data and the backend is a design draft.

Stack: Node.js, Express, Redis, OpenAI API, Anthropic API, React

[Live demo](https://eaglepython.github.io/multi-llm-orchestration-platform/) · [Repository](https://github.com/eaglepython/multi-llm-orchestration-platform)

### AI Ethics Monitoring Dashboard
A prototype for monitoring bias and fairness in AI models, with fairness metrics and compliance views. Runs on simulated data.

Stack: Python, Streamlit, scikit-learn, Plotly

[Live demo](https://eaglepython.github.io/ai-ethics-monitoring-dashboard/) · [Repository](https://github.com/eaglepython/ai-ethics-monitoring-dashboard)
